### 🛰️ Core Focus & Systems Architecture
I design automated infrastructure networks, provision containerized microservices, and build low-latency, event-driven backends. Rather than focusing on frontend frameworks, I spend my time optimizing code execution loops, operating system runtimes, and secure networking paths.

- 🛠️ Currently focused on Infrastructure as Code, automation scripting, and service orchestration.
- 📡 Deep interest in network virtualization, zero-trust edge routing, and data integrity testing.
